# Binascii Rust dependency licenses

The Rust checksum path uses `crc32fast` for CRC-32. Its exact version and
registry checksum are pinned in the overlay `Cargo.lock`.

| Crate | Version | Declared license |
| --- | --- | --- |
| `crc32fast` | 1.5.2 | MIT OR Apache-2.0 |

The crate offers permissive MIT and Apache-2.0 license choices.
