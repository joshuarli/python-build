# Third-party license evidence

`_json_rs` has no target Rust dependencies. Its host-only build dependency is
the existing in-tree `cpython-build-helper` crate.

The private declarations represent the used CPython API and C layouts from
CPython commit `b812b4a7b9efaca46b98544a8633b7d7e454166b`, distributed under the
Python Software Foundation License Version 2. They add no library or crate.
