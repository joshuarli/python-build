## Root cause and resource accounting

`_apply_source_patches()` runs `git apply --check` and `git apply` with `cwd` inside the extracted tree. That tree has no `.git`; Git discovers the enclosing experiment worktree and treats the extracted directory as a path prefix. `git apply --check --verbose` printed `Skipped patch` for all seven patch paths and returned success. With `GIT_CEILING_DIRECTORIES` set to the extracted tree's parent, the same read-only check printed `Checking patch` for all seven paths. The smallest correction is to stop Git from discovering the enclosing repository during application and reject zero-file application; the coordinator owns that driver fix and its regression test.

The timed commands totaled **832.39 CPU seconds**. `doctor`, hash checks, and short inspections were not separately timed. `/usr/bin/time -l` reports the largest process RSS, not a simultaneous aggregate or unique-memory total.
