# Pinned CPython source tarfile read, 2026-09-25

**Verdict: the zlib inflate hybrid regresses this public tarfile workload against the accepted fork control.** Seven serial control/hybrid pairs had a median full-process wall increase of 11.67% and kernel CPU increase of 10.81%. Every pair was slower, including after the first pair's unusually high external wall result. The seven preceding control/control pairs ranged from −0.77% to +0.69% in full wall. Keep this negative breadth result alongside the direct gzip gain; do not promote the hybrid on this evidence. This is a fork-control comparison, not upstream CPython resource parity.

The [workload](source_tar_hybrid.py) reads the real locked `cpython-rust` source `.tar.gz` through `tarfile.open(path, mode="r:gz")`. It visits all 6,539 members, streams the contents of all 6,031 regular files into SHA-256, and includes each regular file's name, size, mode, time, owner, group, and type in the digest. One pass verifies 136,064,031 regular-file bytes; no files are extracted to disk.
