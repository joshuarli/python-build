# Native URL unquote proof, 2026-09-25

## Decision

**Keep the bounded prototype for semantic qualification.** Against a quote-only control rebuilt with the same locked LLVM compiler, adding a Rust percent-byte scan to the existing private extension reduced complete `catalog_search_form` wall time by a median **43.6%** and root kernel user-plus-system CPU by **44.7%** in five serial counterbalanced pairs. The same result appeared against the unchanged accepted extension. Every complete task output and input digest matched the controls. The five matched control/control wall ratios varied at most 1.3% from unity. This is a proof of task speed, not approval for a source patch: broad public `unquote` differential behavior and the relevant CPython regression suites remain unrun under this lane's instructions.

The normalization negative control produced a smaller 2.6% median wall reduction over five pairs. Its 1.3% control/control and candidate/candidate variation is below that observation, but this is larger than the earlier instrumented 1.59% `unquote` cumulative share and the 500-iteration preliminary pass was inconclusive. Treat the normalization result as an unexplained observation, not an independent reason to keep the decoder. The search result is much larger than its same-side variation and is the decision basis.

## Boundary and build

The proof source is `url-unquote-proof/quote.rs`, `module.c`, and `build.py`. It copies the accepted guarded quote stage into ignored `rust-cpython/work/url-unquote-proof-20260925a/{control,candidate}` using APFS clone copies. The accepted stage and its build tree were read only. The candidate changes only installed `urllib/parse.py` and `_rust_url_quote.cpython-316-darwin.so`; the control keeps the accepted installed bytes. `build_matched.py` creates a third clone, `matched-control`, with an otherwise unchanged parser and quote-only extension rebuilt from the accepted source using the same LLVM compiler as the candidate. The source parser anchor and accepted SHA-256 are checked before building. No dependency, toolchain pin, product path, or shared patch manifest changed.

Public `unquote` retains bytes dispatch, the no-percent return, and `None` normalization. After those exits it calls the native helper only for exact `str`, exact codec and error strings, values `utf-8` and `replace`, and an ASCII source. The C helper checks `PyUnicode_IS_ASCII` without a Python prescan and returns the `NotImplemented` sentinel on a non-ASCII source, which makes the unchanged Python generator handle it. C owns object allocation and UTF-8 replacement decoding. Rust writes at most the input byte length, converts only valid two-digit percent escapes, and leaves malformed escapes literal. It does not interpret `+` or URL structure. The existing quote helper and its 200,000-byte guard remain present.

## Attempts, limits, and next qualification

The ignored raw directory `rust-cpython/work/url-unquote-proof-20260925a/` retains a unique `.time` and stdout/JSON plus stderr file for all **129** attempts, including the first Apple clang build, preliminary 500-iteration comparisons, LLVM rebuild, final comparisons, matched-control build and comparison, candidate self-check, import traces, and tree audits. One smoke failed because the harness read the removed module `__cached__` attribute; the corrected harness reads `__spec__.cached`, and both subsequent smoke commands passed. The first tree-audit script selected the wrong directory and produced an empty inventory; the corrected runs compared all 9,552 entries. The compact `url-unquote-proof/measurements.json` records every attempt and installed identity. It lists the absolute raw-log path.

The nineteen top-level `/usr/bin/time -l` commands cover build preparation, child timings, smoke commands, import traces, and tree audits: **68.75 user + 12.35 system = 81.10 kernel CPU seconds**. Controller time includes its children, so child records are not added again. Highest reported process RSS across all attempts was **102,039,552 bytes** during clone/build preparation; every record reported zero swaps. The host had ordinary desktop activity and OrbStack, with no competing compiler or benchmark observed at preflight. The lane stayed below its 180 CPU-second and 2 GiB process-RSS caps. No formatter, linter, hook, or test suite ran.

Before integration, compare public results and exception types/messages against the pinned no-Rust interpreter for all escaped byte values, malformed escapes, mixed non-ASCII source text, subclasses, bytes/bytearray, custom codecs/errors, no-percent identity, long inputs, `unquote_plus`, and `parse_qsl`. Run the existing `test_urlparse` and `test_urllib` suites after promoting a source patch. This proof's complete catalog digests establish workload correctness only.
